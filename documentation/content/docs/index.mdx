# Jindong (진동)

Declarative haptic feedback library for Compose Multiplatform, built with Compose Runtime.

```kotlin
Jindong(trigger) {
    Haptic(100.ms)
    Delay(50.ms)
    Haptic(50.ms, HapticIntensity.STRONG)
}
```
